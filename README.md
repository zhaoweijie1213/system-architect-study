# 系统架构设计师备考（2027 年 5 月）

目标：2027 年 5 月下旬一次通过软考高级「系统架构设计师」三科（综合知识、案例分析、论文，每科 ≥45 分），同时用国外原著把核心模块真正学懂。

思路：**以官方教程和考纲为主线，国外原著按需深入**。原著负责「为什么」，教程负责「怎么答」，两者不一致时考试一律按教程口径。

## 考试要点

- 一年两考（上半年约 5 月下旬、下半年约 10 月下旬），全部机考，三科连续进行，论文需打字作答。
- 三科均 ≥45 分且一次性通过。
- 报名一般在考前两个月左右（往年 3 月）。考试时间、报名节点和机考安排以[中国计算机技术职业资格网](https://www.ruankao.org.cn/)的官方通知为准。
- 官方用书：《系统架构设计师教程（第 2 版）》，20 章，上篇综合知识、下篇案例分析。
