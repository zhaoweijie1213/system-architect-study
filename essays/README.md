## 结构

1. 摘要（300 字左右）：项目、本人角色、论述主题、采用的方法和效果
2. 项目背景：规模、目标、技术选型、个人角色
3. 正文：主题的理论要点 + 在项目中如何落地，每个要点配具体问题和数字
4. 总结：效果、不足、改进方向
